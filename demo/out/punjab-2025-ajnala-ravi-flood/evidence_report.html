7. Limitations

  • Supporting evidence, not an official assessment.
  • NDVI cannot identify the crop; the plot is a square approximation around a point.
  • Monsoon cloud can leave few usable scenes; each pixel is cloud-masked and the scene count is shown.
  • Apparent loss of roughly 10-20% appears on sites with no documented event (natural variation and crop ripening), so small values must not be read as damage.
  • One field is an illustration, not a validation: see the controls and validation table.
